## Modules

| Module | Rôle |
|--------|------|
| NetAdmin | Adaptateurs, hosts, firewall, DNS |
| NetMap | Connexions · ping · proxy · partages · SiteCheck |
| **Traffic** | Trafic live · alertes · réputation opt-in |
| WifiKey | Profils WLAN (confirmation avant action) |

## Pourquoi ce hub

- **Gratuit à vie** — pas d’abonnement, pas de compte
- **Autant local que possible** — pas de phoning home ; **module pas utilisé = pas de sortie liée**
- Sorties **uniquement** si tu agis : hôtes / URL / cibles **que tu saisis** · réputation Traffic **seulement si tu l’actives** · vérif. GitHub **désactivable** dans À propos
- Confirmation avant mutators (DNS, kill, Wi‑Fi…)
- FR | EN · Accueil réseau lecture seule

## Lancer

1. Télécharge le zip de la **Release** officielle  
2. Extrais où tu veux  
3. Lance `Launch-Hub-Reseau.exe` (UAC admin)

Windows peut afficher « potentiellement dangereux » : binaires **non signés** Authenticode. C’est **SmartScreen** (réputation), pas un verdict antivirus.
